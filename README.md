# Group 18 Capstone Project: Planet
TS Academy Frontend Development Capstone Project (Hajime Cohort).
Planet is a responsive web application that recreates the Capstone mockup by [Amaka N](https://amakandukwu.com) using HTML, CSS, and JavaScript. Users can search for planets to view their images and key information, fetched dynamically from a planet data API, and compare planets across the solar system using an interactive facts table. The application supports both Light and Dark modes and is fully responsive across desktop, tablet, and mobile devices.

**Live Site:** https://capstone-project-group-18.netlify.app/

## Features

- **Planet Search.** Type a planet name (or the beginning of one, for example, "mar") and click Search. The card displays the planet's name, image, type, distance from the Sun, mass, diameter, orbital period, temperature, gravity, number of moons, and descriptions
- **Live Data with the Fetch API.** Planet data is fetched from `https://anurella.github.io/json/planet.json`. The data is loaded once and reused for subsequent searches, improving performance and user experience.
- **Light and Dark Mode.** Users can switch between light and dark themes using the theme toggle in the header.
- **Responsive Layout.** The application is fully responsive and adapts seamlessly to desktop, tablet, and mobile devices.
- **Planetary Facts Table.** Displays key information about the planets, including their mass and diameter, allowing users to easily compare planetary data.
